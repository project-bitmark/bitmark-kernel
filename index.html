Bitmark, on Bitcoin's engine.

Bitmark's blocks are Bitcoin's blocks with different rules at the edges. This page loads the unmodified bitcoin-kernel consensus engine live from the CDN and validates real Bitmark blocks in your browser — Bitmark supplies only a chain schema, nothing else.

The auxpow (merged-mining) and equihash rows are the known boundary: those blocks wrap the standard block with extra serialized proof-of-work data, so full decode needs a small Bitmark-side unwrap layer. The 80-byte header identity and SHA256d linkage still anchor them. Bitmark's multi-algo difficulty check is an external layer by design — this page proves structure, merkle and scripts, which covers the SHA256d-anchored majority of the chain trustlessly.

One schema, nothing else

Bitmark provides ~50 lines of chain parameters (schema/chain.js). Codec, transactions, scripts and the merkle tree are Bitcoin's, reused byte-for-byte.

Loaded live from the CDN

The engine is pulled at runtime from @bitcoin-kernel/kernel@v0.0.2 on jsDelivr. No fork, no copy — the same published code that runs bitcoin-kernel.com.

An honest boundary

Seven of eight PoW algorithms use a standard 80-byte header and validate today. Merged-mining and equihash need a small unwrap; difficulty itself stays an external layer.
